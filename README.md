# ENADE Elétrica

App de estudo com as questões do ENADE Engenharia Elétrica (2014, 2017, 2019 e 2023), gabarito oficial do INEP e resolução passo a passo de cada questão.

Acesse: https://rafaellima-cell.github.io/enade-eletrica/

No iPhone: abra no Safari → Compartilhar → "Adicionar à Tela de Início".

Provas e gabaritos: INEP/MEC (material público). Resoluções: explicações didáticas próprias; onde o raciocínio diverge do gabarito oficial, a questão é sinalizada.
